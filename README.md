"The Hundred-and-First Demo" — a one-line joke about working beside an AI coding agent: the demo ran flawlessly a hundred times in rehearsal, then crashed on the hundred-and-first run, the first one with witnesses. The program in `main.ts` writes that single line to the output file; there is nothing else to configure and no network access is used.

## Run it

```sh
node main.ts
```

This writes the joke (one line, 117 characters, with a trailing newline) to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to redirect the output directory for a local run, e.g. `MAKEFUN_OUTPUT_DIR=out node main.ts`.
